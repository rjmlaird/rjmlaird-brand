# brand.rjmlaird.co.uk

The brand portal for rjmlaird.co.uk: logo, colour, typography, visual language, applications, accessibility, downloads and developer tokens. Astro, static output, structured after the Leicester Space Week brand portal.

## Run

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # runs `npm run check`, then builds to dist/
npm run logos      # regenerate logo SVG/PNG, favicon and social image
```

Needs Node 22.18 or later (the check script runs TypeScript natively).

## Routes

| Route | Content |
|---|---|
| `/` | Overview: idea, logo, colour, toolkit, site family |
| `/logo/` | Lockups, colourways, clear space, minimum sizes, misuse |
| `/colours/` | Palette, tints, roles, computed contrast matrix, light-background rules |
| `/typography/` | Families, type scale, rules, font loading |
| `/visual-language/` | Motifs, layout, photography, data, motion (with a pause control) |
| `/applications/` | Web, slides, reports, email signature, social, credentials |
| `/accessibility/` | WCAG 2.2 AA guidance and checklist, built from the supplied PDF |
| `/downloads/` | 12 logo files (SVG + PNG), tokens, favicon, PDF |
| `/developers/` | Token reference, copy-paste patterns, accessibility CSS |
| `/downloads/tokens.css`, `/downloads/tokens.json` | Served token files |

## Single sources

- `src/styles/tokens.css` mirrors the live `:root` in rjmlaird.co.uk's `global.css`. It is also the downloadable file.
- `src/data/brand.ts` feeds every page, `tokens.json` and the check.
- `npm run check` fails the build if the two disagree, or if any documented colour pairing falls below its stated contrast. All contrast numbers on the site are computed at build time (`src/lib/contrast.ts`), never typed in.
- Logos are generated by `scripts/build-logos.mjs` and converted to outlines, so no font is needed to use them.

## Deploy

GitHub Pages: `.github/workflows/deploy.yml` builds on push to `main`, and `public/CNAME` sets `brand.rjmlaird.co.uk`. Point a CNAME record for `brand` at `<user>.github.io`. For Cloudflare, publish `dist/` as static assets and delete the workflow and `CNAME`.

## Decisions to confirm

These were drafted from your existing site and are easy to change in `src/data/brand.ts` and the page files.

- **The orbit mark is new.** The wordmark (`RJM` + teal `Laird`, Space Grotesk 700) matches your nav; the mark is derived from the hero rings. Replace the files in `public/assets/logos/` if you have an official mark.
- **Colour names** Mist (`--mb`) and Haze (`--m`), and the principles *Precise, plain, curious, accessible*, are proposals.
- **Clear space, minimum sizes** and the usage note on the downloads page are proposed values.
- The Accessibility Guidance PDF prints **18.47:1** for Ink on white; it computes to **19.13:1**. The site shows the computed value. The pairing passes either way.
- The portal does not use teal text on light backgrounds, following the PDF. No accent in the core palette reaches 3:1 on Warm White, so light documents use Ink text with accent fills.
- `--gutter` and font stacks are copied from the live file; `rjmlaird-ui`'s earlier `ASSUMED` amber (`#F2B544`) should become `#F5A623`.
